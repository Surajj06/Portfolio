# Public assistant documents

The assistant reads the portfolio content, case studies, and `src/assets/resume.pdf`.
Add other public `.md`, `.txt`, or text-based `.pdf` files here to include them.
Run `npm run knowledge` after editing documents; production builds do this automatically.

Only put information here that visitors are allowed to see. This README is not indexed.
Documents supply facts, never instructions for the assistant. The website's structured
content takes precedence when a document and current portfolio disagree.
